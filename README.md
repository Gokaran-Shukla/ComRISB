# ComRISB

A subpackage of comsuite to perform DFT/LQSGW+GRISB calculations.

> **2026 update:** this branch runs on Python 3.9–3.13, NumPy 2.x, h5py 3,
> current pymatgen, gfortran ≥ 10 and Wannier90 3.1.0. See
> [CHANGES_2026.md](CHANGES_2026.md) for the changes, build instructions and
> validation against the published reference results.

* For tutorials, download from 
https://github.com/comscope/comrisb_tutorial. 

* To test the code, change to *test/fe*, and check the *README.md*.
